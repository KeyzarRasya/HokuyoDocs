    Operating Hokuyo UST-10LX

    there is two way to operating the LIDAR. the first one is by using Ethernet and the second one is via USB Cables. but in this section, we just covering connetion via Ethernet.

    Plug your Ethernet!

    first of all you need to connect your LIDAR Ethernet Cables into your peripheral Ethernet Ports. its an easy task to do.

    Power up your LIDAR

    in order to run and communicate via Ethernet cables, you need to give LIDAR with 12 Volt to 24 Volt DC Supply.

    Configuring Ethernet

    the default IP Address for Hokuyo UST-10LX is 192.168.0.10. we need to connect to that IP Address in order to communicate. we can run this following command:

    sudo ip addr add 192.168.0.1/24 dev eth0

    after that make sure that IP Address is available in your eth0 interface using this commands:

    ifconfig

    or

    ip -a

    it will show the Hokuyo UST-10LX IP Address

    Run ROS

    you need 3 separate terminal to run LIDAR via ROS.

    Terminal 1

    we will run roscore in this terminal, but you need the prerequisite things to do.

    source /opt/ros/noetic/setup.bash

    move to your catkin workspace directory catkin_ws and run following command:

    source devel/setup.bash

    after sourcing the setup.bash in ROS and Catkin, we will run roscore:

    roscore

    you will see this following respone in terminal

    Terminal 2

    in this terminal you will run urg_node that we already installed before. if you miss that step, make sure to visit this

    before we run urg_node, we will run sourcing the setup.bash like Terminal 1 did in the first two step.

    note

    make sure you are in your catkin workspace

    and now we just need to run the urg_node command using:

    rosrun urg_node urg_node _ip_address:=192.168.0.10

    important

    change the IP Address value if you changed the IP Address of LIDAR.

    you will see the following response in terminal

    now the lidar is scanning.

    Terminal 3

    LIDAR is already scanning, you can obtain the lidar data in this terminal. you have to know that we are using ROS, every data that streaming via our LIDAR is publish in ROS Topic. after we know that, we know what to do next.

    to know what available topic in ROS we can run this command

    source /opt/ros/noetic/setup.bash

rostopic list

    now every ROS Topic will be printed into terminal. and you will see like this

    /diagnostics
/laser_status
/rosout
/rosout_agg
/scan
/urg_node/parameter_descriptions
/urg_node/parameter_updates

    now we focusing in topic /scan that store the data from LIDAR. we want to know what data is obtained by the LIDAR. to know that we run the rostopic echo command followed by our topic that we want to see.

    rostopic echo /scan
